## Boundaries rather than unfinished buttons

- Predictions are file-level. Selecting a function uses its owning file; separate function-level supervised accuracy is not claimed.
- ZIPs use an explicitly untrained structural/directory baseline, not fabricated Git history or learned Git/CodeBERT results.
- Test associations are not executed coverage. A safe test sandbox is not part of this local application.
- Hosted-provider live success requires the user's configured credentials. The fallback and invalid-citation rejection are verified without claiming a live call.
- The primary model did not outperform the validation-selected co-change baseline. Improving this requires a new predeclared research protocol and fresh evaluation discipline, not tuning against the already-seen test results.
- Public multi-user hosting/authentication, collaboration, GitHub App integration and distributed Postgres/Redis/Neo4j operation remain optional production extensions. Docker configuration exists but no daemon was available for an execution check.
